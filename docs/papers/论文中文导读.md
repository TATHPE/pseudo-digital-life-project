## 0. 先说三件事

**一、这批论文的共同主题是"遗忘"，不是"记住"。** 9 篇里有 5 篇标题或摘要里直接出现 forgetting / decay / oblivion。这不是巧合：LLM 智能体的记忆系统在 2025 年之后基本解决了"存得下、找得到"，剩下没解决的是"该忘什么、该淡到什么程度、什么时候该说不知道"。这正好是 PDLP 的核心命题。

**二、它们是"智能体记忆"，不是"数字生命记忆"。** 所有系统的目标都是"下一轮任务做得更准、更省 token"。**没有一个把"人格连续性"当约束**，也没有一个做超过几周的长期部署。所以它们的数字只能看趋势，不能当 PDLP 的验收标准。

**三、转换后的 Markdown 里公式是坏的**（双栏 PDF 用文本抽取的固有问题，`(cid:16)`、表格网格、上下标错位）。**读机制和数据请用本导读，读公式请回原文 PDF 的对应页**——我在下文标注了哪些公式是我从残片反推的。

## 2. FadeMem —— 最该读的一篇（阿里国际 + 北大）

**它要解决什么**：LLM 智能体的记忆只有两种状态——全留着（撑爆上下文）或全丢了（断片）。人类不是这样的：不重要的细节会"淡"，重要的会被强化。

**它怎么做的**（四个动作）：

1. **双层记忆，两种忘速**。一层放长期稳定的（LTM），一层放近期活跃的（LML），两层各自的衰减速度不同。类比：你记得"我在做 PDLP 这个项目"（长期），但不记得"上周二下午我在想什么"（短期）。
2. **记忆强度按"拉伸指数"衰减**：

   ```
   v(t) = v(0) · exp( −λ·(t−τ)^β )
   ```

   这个公式是**我从它的半衰期表达式 `t½=(ln2/λ)^{1/β}` 反推的**（原文公式区在转换时被打散）。关键是 `β` 这个指数：
   - `β = 1`：普通指数衰减，前后段等比例下降；
   - `β < 1`（它给 LML 用 0.8）：**前段掉得快、后段拖长尾**——这最像真实遗忘，细节三天就模糊，剩下的一点能挂很久；
   - `β > 1`（LTM 用 1.2）：先稳住，之后才开始淡。

   顺带一个具体数：`β=0.8`、`λ=0.1` 时半衰期约 **11.25 天**。
3. **重要性直接压慢衰减速度**：`λ_i = λ_base · exp(−μ·I_i)`。注意它进的是**速率**而不是初始分数——意思是"重要的东西不是起点更高，而是掉得更慢"，这两件事在长期行为上完全不同。
4. **升/降级用两个不同的门槛**（滞后）：升到上层要 ≥ 0.7，掉回下层要 < 0.3。原文明确说这是为了防止震荡（"introduces hysteresis that prevents oscillation"）。**这条我原来写错了**，我们之前用的是一对独立门槛，会让记忆每晚反复升降。
5. **冲突用 LLM 判断**：找相似度高的旧记忆，让 LLM 决定怎么处理；同主题的旧记忆聚成簇后让 LLM 融合成一条，融合后的初始强度取 `max(旧强度) + ε·方差`（比任何一条都略强一点）。

**数字**：在 Multi-SessionChat / LoCoMo / LTI-Bench 上，多跳推理与检索不降反升的同时，**存储减 45%**；MSC 上 RP@10 = 77.2%、时间一致性 0.82；LLM 引导的冲突消解达到 68.9% 的多跳 F1。消融里砍掉冲突消解那部分，多跳 F1 从 29 点掉下去。

**它没解决的**：全靠 LLM 判断冲突/融合 → 不可复现、不可审计；没有"人格"概念；双层是手工设的，不是学出来的。

**对 PDLP 的意义**：`β`、重要性调速率、双门槛滞后这三件直接能用；它的"融合"要谨慎（我们规定压缩必须可回退）。

## 3. DISCERN —— 最重要的一篇"反向证据"（Amazon）

**它要解决什么**：企业 agent 跨几十个会话攒记忆，事实互相矛盾、旧值被取代、名字像的实体在向量空间里糊成一团。作者的判断很尖锐：**这不是检索问题，是"解析"问题**。

**它怎么做的**（两句话）：

- **写的时候保守到极致**：建一个**只增不改**的"双时间（bi-temporal）溯源图"。两条时间轴分别是"这件事什么时候发生"和"我们什么时候知道"。规则是：**永不合并可能混淆的实体，永不丢弃被取代的旧值**。
- **读的时候才解析**：查询进来，用一个**不用 LLM** 的工具面在图上走，最后必须落在一个"门控终点"，四选一：**直接回答 / 要求澄清 / 放弃回答 / 索取更多证据**。

其中两个设计值得单独说：

- **`EarnedAbstainGate`（挣来的放弃）**：只有**证明了信息不存在**才允许说"不知道"。这只是"我记得没有"，还不够；必须是"我查过，确实没有"。
- **引用强制**：每个给出的答案必须带证据引用，否则不允许输出。

**数字**（自建合成基准 ENT-310，310 条查询 = 210 可答 + 100 不可答）：

| 指标 | DISCERN | 8 个基线里最好的 |
|---|---|---|
| 拒答 F1 | **0.924** | 0.802 |
| 综合答案正确率 | **0.861** | 0.806 |
| **实体消解** | **0.800** | **不到 0.40** |
| 保留 / 时效性 | 各系统都在 0.93–0.98（**已饱和**） | — |

那 210 条可答题分四类：保留事实 84 条、时效更新 40 条、污染隔离 71 条（问到 A 不能把 B 的事实混进来）、实体消解 15 条。不可答的 100 条是两类陷阱：**属性替换**（拿一个真实体问它没有的属性）和 **近似错配**。

**它没解决的**：基准是自己合成的（作者也承认），企业销售场景，10 个 actor；"零 LLM 的图上行走"依赖人工设计的工具面。

**对 PDLP 的意义**：这是本次最重要的发现。**它证明了"召回率"这个指标已经没意义**——所有像样的系统都在 0.93 以上。真正的差距在"该不该答、指的是谁、哪个是现在"。我们之前把 `recall@5` 当头条指标，等于在优化一个已经解决的问题。

另外它跟我们的设计**有一处正面冲突**：我们写的是"相似度 > 0.92 就合并/取代"，它说**永不合并**。这条需要改（但按你说的，现在不动手）。

## 4. Oblivion —— 读写分离的工程实现（NEC Labs）

**它要解决什么**：现在的 agent 记忆是"always-on 检索 + 扁平存储"，历史一长，干扰和延迟都爆炸。

**它怎么做的**：把"读"和"写"当成两条回路，四个模块分工——

| 模块 | 干什么 | 类比 |
|---|---|---|
| `Decayer` | 按记忆里"易得性"分数持续下调 | 记忆自然变模糊 |
| `Activator` | 查询进来时，**先决定要不要检索、检索多少**，还是直接不查 | 想一下"这事我需要翻记忆吗" |
| `Recognizer` | 识别记忆属于哪个簇，并记住"这类问题该怎么处理"的元指令 | 形成处理经验 |
| `Manager`（Executor） | 总调度 | 前额叶 |

两个细节：

- **双信号门控**：第一轮用"或"（宁可多检索，保召回），后续轮次用"与"（避免缓冲区已经装满了还在重复查）。这个自适应切换挺巧。
- **不确定才有记忆的"层次"**：高层策略长期保留，细节按需加载。

**数字**：在 **120K 交互跨度**下，token 成本降最多 **73%**；某基准上 79.70%（对比基线 60.40%）；有个任务是"单次早期强化 → 后续分段仍能持续"的场景，能到 89.60%。

**它没解决的**：模块名很漂亮但实现细节依赖具体任务分布；"元指令"那套（每个簇学一套处理策略）在单用户场景可能过拟合。

**对 PDLP 的意义**：`Activator`（检索前先判断要不要检索）是我们完全缺失的角色——我们现在的 `search` 是"有查询就无脑跑"，多轮对话里会重复注入。这是很实际的一个改进点。

## 5. RecMem —— 本地算力不够时最该抄的一篇（CUHK + 华为）

**它要解决什么**：记忆系统的钱和延迟大部分花在"用大模型把原始对话提炼成记忆"这一步。能不能少调几次？

**它怎么做的**：学人脑的"先缓冲、后固化"。

1. 原始交互先丢进一个**便宜的缓冲区**，只用轻量 embedding 建索引，**不调 LLM**。
2. 只有当新交互在缓冲区里**找到足够多相似的邻居（复现）**时，才触发 LLM 做固化——把多次零散的经历提炼成一条结构化记忆。
3. 阈值很关键：它默认 `k_sub=10`、`k_epi=5`；实验里阈值从 5 提到 6 时性能明显掉，说明**不能太贪**。

类比：你不会记住每一次有人说"今天好累"，直到这事反复出现，你才形成"他最近工作压力很大"这条印象。**重复是固化的信号。**

**数字**：记忆构建的 token 消耗对三个 SOTA 系统最高降 **87%**；LoCoMo 上 **7.8 倍**；LongMemEval-S 上相对降 77.5%。

**它没解决的**：只关心"效率"，对"忘得太快"没有防护；复现检测用相似度阈值，判断比较粗。

**对 PDLP 的意义**：本机 8GB 显存是硬约束，而"每晚无差别抽取"的预算根本撑不住。它的做法把算力集中到真正反复出现的主题上，而且"重复才沉淀"本身也更像人。

## 6. FSFM —— 遗忘的分类学（中国移动九天）

**它的价值不在算法，在把"遗忘"拆清楚了**。它把遗忘机制分成四类：

| 类型 | 意思 | 对应 PDLP 的 |
|---|---|---|
| 被动衰减 | 时间久了自然弱 | 叙事层的权重衰减 |
| 主动删除 | 用户/系统显式删 | `forget` 工具 |
| **安全触发** | 检测到恶意、隐私、敏感内容 → 主动遗忘 | **我们只有"标记不可信"，没有"主动删"** |
| 自适应强化 | 反复使用的东西被巩固 | 再巩固 / access boost |

第四类里有个具体做法值得记：**危险内容给 -10 的基础惩罚分**，保证容量吃紧时它第一个被挤出；同时容量只用到 70%（留余量），这样**保留超过 70% 的高价值内容**。

**数字**：访问效率 +8.49%，内容信噪比 +29.2%，危险内容**100% 拦截**，内存效率优化 30%，响应速度提升 31 倍。

**它没解决的**：这篇的"实验"更像工程报告（横向+纵向抽样），不是严格的基准对比；"安全触发遗忘"的判定标准没讲细。

**对 PDLP 的意义**：给我们补了一类缺失的机制——**T4 权限禁止"读"，但已经读进来的东西怎么办？** 需要"检测到敏感/恶意 → 主动删除"这条通路，两者不是一回事。

## 7. ZenBrain —— 15 个机制的架构提案，价值在方法论

**它主张什么**：现有系统最多整合 2 个神经科学机制，所以提出一个整合 15 个的 7 层架构。7 层是：工作记忆、短期、情节、语义、程序、核心、跨语境（这是认知心理学 60–80 年代的经典划分）。15 个机制包括：双因子突触固化、**神经调质引擎**（多巴胺/去甲肾上腺素/5-羟色胺/乙酰胆碱四个通道，影响学习率与探索）、**再巩固引擎**、**三副本记忆**、优先级图、稳定性保护（只有预测误差超过 `0.5+0.3Lρ` 才允许覆盖旧记忆）、元认知监控（跟踪确认偏误、近因偏误）。

三个副本的设计挺有意思：同一信息存三份，快（τ=4 小时，指数）、中（14 天，指数）、深（7 天，对数），实际强度取三者最大值。结果 30 天后还能保留 **91.2%**。

**但这篇真正的贡献是一句自我拆台的话**：

> 同一批 15 组消融实验，当衰减压力是 0.15/天时，只有 **1/15** 的机制显著；把压力提到 0.25/天，变成 **9/15** 显著，其中 5 个从"完全看不到效果（0%）"掉到 "−93.7%"。机制一个都没改，只有压力变了。
> 它把这个现象叫 **cooperative masking（协同遮蔽）**：在协同冗余的系统里，**轻度负载下的单机制消融，会对真正承重的机制报出"零贡献"**。

**它没解决的**：单作者架构提案，自建基准（11,589 个 CI 测试），数字里有一处对 Letta 的 Docker 服务 500 报错的处理不太公平（500 条查询里 Letta 失败 59 条，作者把它算作 Letta 的失败）。另外它自己说"现有系统没有一个整合超过两个机制"——这种话要打折听。

**对 PDLP 的意义**：不是抄机制，是**警告评估方法**。我们如果在"温和"条件下跑评测，会得出"衰减没用，删了吧"的结论。必须跑两档压力（比如半衰期 30 天 vs 7 天）才能看出机制是否在起作用。

## 8. TSUBASA —— 长时程个性化（Michigan）

**它要解决什么**：个性化模型要长期贴合一个人，但每次都靠 RAG 把记忆塞进上下文太贵，而且效果有上限。

**它怎么做的**：两条腿走路。
1. **演化记忆**：从交互里持续抽取关于用户的高密度观察（不是原文，是观察），记忆随交互演进；
2. **上下文蒸馏**：把记忆"内化"进模型（用蒸馏训练），让它不靠检索也会；
3. 但结论明确写着：**显式的 RAG 支撑仍然必要**——内化不能完全替代检索。

**数字**：单轮和多轮任务提升 **17%–49%**；显著超过 Memory-R1，比工业界 Mem0 高 **35–50%**。

**它没解决的**：需要训练模型（我们本地跑 4B、主力在云端，做不了蒸馏）；"观察抽取"的质量高度依赖抽取模型。

**对 PDLP 的意义**：支撑了我们的一个结构选择——**人格风格用"内化"（`voice.md` 的 few-shot 样本），事实用"检索"**，两件事不该混在一起。另外它做的"用户偏好漂移追踪"正是 `self_state` 和 `preference_soft` 该管的。

## 9. Sleep's Contribution to Memory Formation —— 120 页综述，`01 §9` 的生理依据（Physiol Rev 2026）

**一句话**：睡眠不是"休息时顺便整理记忆"，而是**记忆形成的必要环节**。这篇把几十年证据汇总了，教科书级。

对工程有直接意义的四点：

1. **巩固是主动过程**。新记忆一开始不稳定，需要离线期的"再激活"才能变成长期表征。**而且"回忆"本身会让记忆重新变得不稳定，并可能被更新**——这叫再巩固（reconsolidation）。所以"想一次就更牢、也可能被改写"是有生理依据的，不是我们的偷懒设计。
2. **TMR（靶向记忆再激活）**：在人睡觉时用气味或声音放线索，能显著提高对应记忆的保留。→ 映射到工程就是"夜间整理时，按当天出现频率给记忆加权"。
3. **SHY（突触稳态假说）**：清醒期突触整体变强，睡眠期**整体下调**，保留强的、削弱的被修剪。→ 这解释了为什么"统一缩放 + 相对排序"比"绝对阈值"更稳，也是我们夜间全库重算的理论依据。
4. **抽象化**：睡眠不只是保留细节，还会**提炼要点**（gist）。→ 支持"从多条具体经历中融出一条一般性记忆"，但要限频（融合会丢细节）。

**它没解决的**：这是人类生理研究，不能直接移植到机器上；证据强度在不同结论间差异很大（有些是强因果，有些只是相关）。

**对 PDLP 的意义**：`01 §9` 的夜间整备流程不是拍脑袋，逐条都能对上这四条。

## 10. Engram / Synapses —— 为什么"永不遗忘的那一层"也需要每天维护（Frontiers 2021）

**它研究什么**：记忆在脑子里到底以什么形式长期存在。所谓 **engram（记忆痕迹）**，就是"学习时被强烈激活的那一小群神经元"，这群细胞是记忆表达所必需的——实验显示，学习后**至少 1 个月**它们仍是必需的。

**它提出的矛盾**：记忆能稳定存在一个月以上，但**突触蛋白的周转速度很快**（几天就换一批）。那么"持久的连接增强"怎么可能靠一个静态结构维持？

**它的回答**：不可能。所以持久性只能来自**持续的动态更新**——突触不停地被替换，但整体的连接强度维持在一个稳定水平。作者给了几种候选模型，核心思想都一样：**"稳定"是一种动态平衡，不是一块石头。**

**它没解决的**：分子层面仍有争议，是综述不是定论。

**对 PDLP 的意义**：这一条修正了我对"契约层"的解释。我们说"契约层永不衰减"，容易理解成"存进去就不动"。正确的理解是：**它需要每晚被重新确认一遍**——检查它是否被新叙事反驳、是否还一致——只是**权重不变**。永不衰减 ≈ 每天都在被动维护，而不是"被遗忘在数据库里"。

---

## 11. 把 9 篇合起来看：它们讲的是同一个故事

```
过去两年大家都在做同一件事：让 agent 记住更多。
现在发现记住不是问题（DISCERN：召回率全部 0.93–0.98，已饱和）。

于是问题变成三个：
  ① 该淡的淡了吗？        → FadeMem（衰减曲线）、FSFM（遗忘分类）
  ② 该忘的忘了吗？        → RecMem（只在复现时固化）、Oblivion（读写分离）
  ③ 该说不知道的时候说了吗？ → DISCERN（拒答 F1、四态门控）

支撑这三个问题的底层机制：
  · 人脑怎么做的      → Sleep 综述（巩固/再激活/抽象化）、Engram（持久性靠动态维持）
  · 多个机制叠加怎么评 → ZenBrain（cooperative masking：轻负载下测不出效果）
  · 个性化怎么长期演进 → TSUBASA（观察抽取 + 内化 + RAG 兜底）
```

**一个尖锐的共同点**：这 9 篇没有一个在讨论"这个系统记得的东西是不是真的发生过"。它们假设输入是干净的对话日志。而 PDLP 面对的第一个大坑恰恰是——**模型会编造没有发生过的共同回忆**。这是它们全部没有覆盖的空白，也是我们最该自己做的部分。

---

## 12. 这些论文的四个盲区（别被数字带跑）

1. **场景错配**：6 篇是**多用户 / 多 agent / 企业**设定（DISCERN 是 10 个 actor 的企业销售 agent，FadeMem 是对话基准，RecMem 是任务型 agent）。PDLP 是单用户、长时程、要求人格连续。它们的"准确率"不能直接当我们的验收。
2. **没有长期部署**：最长的是 120K 交互跨度的模拟（Oblivion），没有一篇报告"用了半年之后会怎样"。而人格漂移恰恰是半年尺度才暴露的问题。
3. **基准多为自建合成**：DISCERN 的 ENT-310 明确 synthetic；ZenBrain 自建 11,589 个 CI 测试；TSUBASA 也是自建。数字看趋势，不要当定论。
4. **"遗忘"的代价没被评估**：所有论文都在报"省了多少 token / 存储"，**没有一个报"忘掉了哪些本该记住的东西"**。而这正是 PDLP 最不能出的错——忘记一个承诺比多存 10 条闲聊严重得多。

## 13. 术语小词典（读原文时会遇到）

| 词 | 中文 | 意思 |
|---|---|---|
| engram | 记忆痕迹 | 学习时被激活、之后负责"表达"这段记忆的那群神经元 |
| consolidation | 巩固 | 新记忆从脆弱变稳定的过程（主要发生在离线/睡眠期） |
| reconsolidation | 再巩固 | 回忆会让记忆重新变得不稳定，并可被更新；"想一次就更牢"的机制 |
| systems consolidation | 系统层巩固 | 记忆从海马体"搬"到皮层长期存放的过程 |
| TMR | 靶向记忆再激活 | 睡眠中用线索提示特定记忆，提高其保留 |
| SHY | 突触稳态假说 | 清醒期突触整体增强、睡眠期整体下调，保留强的修剪弱的 |
| episodic / semantic | 情节 / 语义 | "上周二他说了什么" vs "他喜欢简洁的回复" |
| bi-temporal | 双时间 | 同时记录"事情何时发生"与"我们何时得知"；处理旧值被取代的关键 |
| abstain | 拒答 | 明确表示"我不知道/库里没有"，而不是给一个近似答案 |
| gist | 要点 | 从多个具体经历中提炼出的一般性结论 |
| hysteresis | 滞后 | 上升与下降用不同门槛，防止状态反复横跳 |
| cooperative masking | 协同遮蔽 | 多个机制互相兜底时，单独拆掉一个看不出效果 |
