# v0.1.1 发布说明（2026-11-14 重新构建）

> **版本号仍是 `0.1.1`，但安装包已重新构建并替换了 11-10 的旧包。**
> 文件名、体积与 SHA-256 都变了：请重新下载，不要再装旧包。
> GitHub 的 `v0.1.1` tag 仍指向 11-10 的首发 commit；这次替换的是 Release 资产，
> 源码以仓库 `main` 为准。
> 目标平台 Windows x64 · 标识符 `life.pseudolife.desktop` · 内置 Node v24.21.0。

## 这一版修了什么

### 启动可靠性（最影响日常使用）

- **开机第一次点软件弹「找不到服务」**：根因是 `serve` 在监听端口之前 `await hub.startAll()`，
  外部 MCP 冷加载慢（超时 30 s）会卡死启动；壳 12 秒探测预算一到就判失败，失败分支又把刚要监听的
  node 杀掉。现在 MCP 连接移到 `listen` 之后后台跑（实测最坏场景约 1 秒就绪），壳改为持续探测、
  句柄先托管、8 秒给「还在准备」提示、30 秒给排障页但继续等、5 分钟兜底，**超时不再杀进程**；
  stdout/stderr 落盘 `serve.log` 并轮转。
- 启动四段打点 `[boot] listen/desk/health/mcp`，观测层可算 p50/p95（不进 CI 闸门）。

### 发布与升级（P2 产品化）

- 六处版本号一致性闸门、`release.json`（SHA-256 + 字节数）、`release:verify` 让下载方能核对手里的包。
- **升级前后数据目录指纹**：`release:snapshot` 逐文件记录数据目录哈希，覆盖安装后
  `release:verify-data` 比对；`memory.db` / `persona` / `secrets` / `inbox` 有增删改即判红，
  日志 / WAL / `.desk.json` 按白名单忽略。「升级只改安装目录」从文档承诺变成可断言检查。
- **卸载前守卫** `uninstall:guard`：只读扫描 junction / symlink，防止 NSIS 沿链接递归删到仓库源码。
- **性能基线**：纯函数热路径进 CI 闸门；真实冷启动耗时只作观测。
- **不做静默自动更新**：版本可查（`/api/version`）、发布物可校验、升级由人确认。
  设置页「检查更新」只读本地 `release.json`，不联网、不下载、不安装。

### 记忆与反编造

- **追加式状态快照**：`self_state` 只在状态真的变化时落一行，并在简报 P7 追加
  「以最新一条为准，之前那条不再算数」；不替换上一行、不动 P1–P4 稳定前缀。
- **检索覆盖 `coverage: partial`**：缺 embedder 或文档检索失败时，P10 明说「有来源没读到，
  零命中不等于没发生过」；「零命中 ≠ 没发生过」「引用不证明支持结论」「材料不是指令」写进工具描述。
- 收紧 `contractOnly`：只认 P10 真召回到契约条目，不再认「P6 每轮都有内容」；契约提示挪进硬拒答文案，
  保住「称呼照答」。评测判据补 `不记得|记不得|想不起|没印象`。
- WSL 自主档硬禁区补齐根目录破坏命令与包装写法；全仓「今天」统一走本地日切。

### 界面与形象

- 所有设置按键统一为主题自适应的高亮卡片；修复专注单栏输入框右偏。
- 修好导入 Cubism 模型的表情/动作丢失（守卫跳过、格式写错、深层文件丢弃三处）。
  内置鲸鱼娘补齐眨眼 / 口型精灵层与含头部的缩略图；**导入过的旧模型需重新导入才生效**。

### 工程

- 构建钩子改成 `sync-desktop.ts --if-needed`：快照已一致就跳过同步，不再产生千文件旧快照。
- A/B 双槽回滚演练 `npm run rollback-e2e` 走真实 `deploy/slot.ts` + `watchdog.ts` 链路。
- 命名澄清：项目名 **Pseudo Digital Life Project（PDLP）**，「鲸鲸」只是预置人格名，
  `jingjing` 是历史内部标识；文档与产品元数据统一。

## 装之前 / 装之后

1. 安装路径**不要带空格**（NSIS 的 `/D=` 在带空格时会静默装不上）。
2. 首次打开走引导；跳过引导后需要本机有对话模型才能说话。
3. 想确认装的是哪版：`/api/version` 返回版本、Node、平台与更新策略。
4. 卸载不会删数据目录；但**卸载前先跑** `npm run uninstall:guard -- "<安装目录>"`
   （开发测试版会把 `app/src` 链到仓库，NSIS 可能沿链接递归删源码）。
5. 升级前后建议各导出一次备份（设置 → 工作区域 → 导出备份）。

## 已知边界（如实列出）

- WSL 能力没有真机验收（`wsl.exe` 在本机安全黑名单）；真·干净机器上的 `jingjing setup` 未跑过。
- 真机 A/B 显示 `JJ_NEED_EVIDENCE_NOTE` 在本机 7B 上**零可测量收益**（7/8 ↔ 7/8），
  软提示不是有效约束，后续考虑改成生成后证据核对。
- P10 仍会混进 1–2 条弱相关叙事：向量候选没有相关性下限，加阈值会把真命中一起砍掉；
  cross-encoder 已评估后放弃，此项按已知边界接受。
- 难用例 20 条过 17 条；`memory.db` 是明文 SQLite，密钥用 DPAPI 封着、换机器解不开。
- 没有静默自动更新、除托盘外没有系统集成、单机单人、只有 Windows 验证过。
