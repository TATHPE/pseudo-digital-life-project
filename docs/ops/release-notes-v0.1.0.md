## 0.1.0（2026-11-09 第三次重建）

同一版本号的第三次构建：代码比 11-07 那一版新两天，**请用这个包**。
产物 `Pseudo Digital Life Project_0.1.0_x64-setup.exe`（32.6 MB，2026-11-09 20:09 构建）。

### 这一版比 11-07 多了什么

- **召回层配额**：契约层权重恒 1.00、永不衰减，夜间抽取大量产出会把叙事证据挤出固定 k 窗口。按原排名遍历、契约最多 2 条（`JJ_CONTRACT_CAP`，`-1` 关闭），叙事不足时用跳过的契约补位，最后仍按原排名排序。
- **重排 NONE 保守回退**：本地 7B 说「都没有」时不再清空候选（实测 nightly 有 3 题整轮归零，答成「我没有相关记录」的错误否认），只把 `confidence` 降到 `need_evidence`。`JJ_RERANK_NONE_FALLBACK=0` 可回旧行为。
- **简报总预算真收口**：`budget.total` 以前只赋值、从未读取，各槽位只管自己的分项预算。现在按可丢弃优先级逐槽让位（P18→P19→P17→…→P7），稳定前缀、P5 时刻、P6 契约、P10 召回与反编造硬提示、P11 用户输入一律不动。
- **P10 带「多久以前」**：`weight` 不是时间，契约层恒 1.00，45 天前的约定和今天的在简报里长得一样。现在从 `created_at` 渲染成 `今天 / 3 天前 / 1 个月前`（粗粒度，越精确越像在假装记得清楚）。
- **装配层基准** `npm run eval:assembly`：走真 `recallForBrief → buildBrief`，判隐私泄漏 / 契约标签 / 时间 / 预算 / 进没进 P10 / 拒答与编共同回忆。原来四套 eval 都只测 `search()` 的返回顺序，这一段是盲区。
- **工程清理**：`ensurePolicy` 每次启动自增两行（445 → 27 条唯一，按 (tier,verb) 解析）；`server.ts` 2816 → 1361 行（路由抽成 config/setup/memory/control/status 五族）；`pathsafe.ts` 断掉模块循环（SCC 2 → 0）；红队 21 条首次进 CI。
- **测试**：673 → 696。

### 已知边界（沿用 11-07，未变）

- 任务编排一次只推进一步，没有计划树、没有并行。
- `memory.db` 是明文 SQLite；密钥用 DPAPI 封着，换机器解不开。
- 没有自动更新；单机单人；只有 Windows 验证过。
- 难用例 20 条过 17；2 条「该拒答却答了」属本地 7B 的校准边界。
- P10 仍会混进 1–2 条弱相关叙事（向量候选没有相关性下限，cos 0.49–0.60 与真命中 0.72 一起进窗口）——调阈值会砍掉真命中；cross-encoder 已于 2026-11-10 评估后放弃（见 `docs/ops/24`「决策：不上 cross-encoder reranker」），此项按已知边界接受，不是待办。

## 0.1.0（2026-11-07 重建）

同一版本号下的第二次构建：代码比首个 0.1.0 包新了整整一天，**请用这个包**。

### 新增

- **任务编排**：`task` 命令 + 记录本里的「任务」页。写一句目标，她一步一步做；每一步都要另问一次「这步达成没有」，连续两步没进展就挂起去问你。心跳每 10 分钟顺带推进一步（`JJ_TASK_TICK=0` 可关）。
- **本地兜底**：云端接不上时用本机对话模型顶上。上下文一个字不少（人格、召回、最近几轮都在），但**不能调用工具**——顶栏常驻琥珀色「本地 · 模型名」，鼠标悬停说明原因和恢复条件；云端成功调用一次就自动切回。
- **聊天 / 工作自动切档**：按你这句话自己判（带命令、带路径、多步骤、动词带宾语 → 工作；寒暄、回忆、情绪、问句 → 聊天），短句沿用上一轮不来回跳，也能手动钉住。chip 三态：自动 → 聊天 → 工作 → 自动。
- **动效**：她开始回话时左侧竖线从顶端长起来；流式正文末尾有方块光标；面板切换与横幅是短淡入。全部尊重 `prefers-reduced-motion`。
- **主题统一**：深色与 Hermes（浅色）共用同一套语汇——同一套间距节奏、字号阶、等宽数字、选区与光标颜色。

### 修复

- **本地兜底会编造命令输出**：实测它会贴出一段假的 `npm test` 结果（"25/30 tests passed"，那个测试文件根本不存在）。根因不是模型笨，而是**简报里写着「完全权限：能跑命令」而调用没给工具**——两边矛盾，模型按简报办事。现在 `noTools` 会同时：空工具表、把权限句改成「本次没有工具」、关掉讨计划的回路。
- **`cloudReady` fail-open**：配置读不到时会被当成"云端可用"，让本地模型拿到完整工具表。改成 fail-closed。
- **兜底说明说假话**：没有 key 时以前仍先撞一次 401。现在直接本地，notice 照发。
- **chip 刷新后永远显示「自动 · 聊天」**：重新加载时丢了服务端判定的档位。
- **粘性档位是进程级的**：跨数据目录、跨测试共享。现在每个 server 一份。

### 无障碍

- Tab 第一下出现「跳到内容」，目标可聚焦。
- 顶栏反馈与她的回答都有 `aria-live` 播报。
- 所有去处的导航项可键盘走、有 `:focus-visible` 焦点环。

### 已知局限

- 20 条手写难题过 17 条；「该说不知道却答了」还剩 2 条，是本地模型的校准边界（`docs/ops/24`）。
- 任务编排一次只推进一步，没有计划树、没有并行。
- `memory.db` 是明文 SQLite；密钥用 DPAPI 封着，换机器解不开。
- 没有自动更新；单机单人；只有 Windows 验证过。

### 校验

- `npm run check`：673 条测试全绿
- `npm run ui:test`：52 项真点真发全绿
- `npm run desktop:check`：11 项全绿
- 安装路径**不要带空格**（NSIS 的 `/D=` 在带空格时会静默装不上）
