## 0. 一句话

**鲸鲸 = 只在你机器上活着、用本地模型维护记忆、用云端模型思考表达、随时间变化而不重置的对话主体。**

v0.1 把它写成了"给任意 Agent 用的本地记忆基础设施"。那是**工具**的定位，评的是召回率。现在改成**存在**的定位，评的是连续性——召回率只是必要条件，不是目标。这不是换个说法，它改了四件事：加了时间维度（衰减）、加了自我（人格与状态）、加了主动性（心跳）、加了行为（手脚）。

## 1. 怎么算"活着"：五条可检验的判据

伪数字生命最容易滑向"套了个名字的聊天机器人"。所以先把"活着"翻译成能测的东西：

| # | 判据 | 可检验形式 | 失败长什么样 |
|---|---|---|---|
| L1 | **连续时间轴** | 能正确说出"距上次聊 3 天 4 小时""你上周二提过 X" | 每次都像第一次见面；或把三个月前的事当今天 |
| L2 | **有衰减** | 三个月没提的事，不会成为今天回应里的重点；近期高频关注的会浮现 | 复读机（什么都记得一样重）或失忆症（每次重修） |
| L3 | **有主动权** | 在没有用户输入时也会醒来、整理、偶尔发起 | 只有你戳它才动 |
| L4 | **有自我叙事** | 能回答"你最近在想什么""你怎么变成现在这样的" | 答案来自数据库字段拼接，没有"我" |
| L5 | **换了引擎不换人** | 云端主力从 A 换到 B，说话方式、记忆、态度不变 | 换模型=换人，人格归零 |

L2 是这次改动里**技术上最重**的一条，见 `01 §4`。L5 是**架构上最容易做砸**的一条，答案是要有独立的"灵魂文件"（§5）。

## 2. 三条铁律

分歧点会不断出现（要不要记住这句？要不要主动说话？这个操作能不能做？），这三条用来砍：

### 铁律一：会腐烂的是叙事，不能腐烂的是契约

记忆必须分两层，混在一起无解：

| 层 | 内容 | 时间行为 | 例 |
|---|---|---|---|
| **叙事层** `narrative` | 感受、片段、闲聊、情绪、当时的想法 | 按权重衰减，会淡、会沉底、可被强线索唤醒 | "10 月 24 号你加班到很晚，说话有点冲" |
| **契约层** `contract` | 承诺、边界、硬约束、身份设定、明确要求记住的事实 | **永不衰减**，只能显式变更（带 supersedes 链） | "别叫我助理""不要在我工作时主动打扰""我住在杭州" |

为什么必须有这一刀：只有叙事层 → 人格失真（三个月前的情绪权重等同今天，等于没活）；只有契约层 → 不可靠（每次都要重新交代）。**生命感来自衰减，可靠性来自不衰减的那一小部分。** 任何一条记忆写入时必须二选一，不允许"未分类"。

### 铁律二：记忆在本地，表达在云端

云端模型只收到**装配好的此刻**（persona 块 + 召回的少量记忆 + 当前状态 + 本轮输入），不是数据库，不是全历史。数据库永不出本机。

### 铁律三：行动必须可恢复，或必须留痕

鲸鲸可以自己做事，**包括不可逆的事**——前提是做错了能回来。

约束从"少给权限"改为"**控制爆炸半径 + 保住恢复路径**"（`04 §4.4` / `04 §6`）：

| 半径 | 范围 | 策略 |
|---|---|---|
| 1 | 鲸鲸自己的专属设备（任何一台它为唯一主人的机器） | **可以给 root**：自动快照 + 全量审计 + A/B 回滚 |
| 2 | 你的主力机、NAS、共享盘 | 独立账号或只读挂载，动作全记录 |
| 3 | 密码库、银行、主邮箱、域名控制台、备份的备份 | 不给（不是不信任它，是任何自动化系统都不该有） |

唯一的绝对禁区：**不许损坏自己的审计与备份**。不是为了防它作恶，是为了防**它把自己弄死**——一个会自我修改的进程，一次坏的 `apt upgrade` 就能把"小房子"变成砖头，那不是自由，是死亡。（细节见 `04 §4.4`）

## 3. 系统结构：三模块 + 一个钟

```
                        ┌─────────────────────────────┐
                        │  生命钟 heartbeat (cron)     │  ← 每秒/每天/每周 三层节拍
                        └──────┬──────────────┬───────┘
                               │              │
    ┌──────────────────────────▼──┐   ┌───────▼──────────────┐
    │  记忆模块（本地 LLM）         │   │  执行模块（手脚）      │
    │  · 抽取 / 归并 / 冲突消解     │   │  · 调度、工具、沙箱     │
    │  · 权重衰减 / 休眠 / 唤醒     │   │  · 门禁、审计         │
    │  · 夜间反思 / 写自传          │   │  · 建议：薄循环 + MCP   │
    └──────────┬───────────────────┘   └───────┬──────────────┘
               │  读/写                          │  调用
        ┌──────▼──────────────────────────────────▼──────┐
        │   存储与索引层（02）：SQLite + FTS5 + vec       │
        └──────▲──────────────────────────────────────▲──┘
               │  装配好的"此刻"（≤1500 token）          │
    ┌──────────┴──────────────┐              ┌──────────┴───────┐
    │  推理模块（云端 API）      │              │  用户 / 外部世界   │
    │  · 共情表达、复杂推理      │              │                  │
    │  · 人格一致的输出          │              │                  │
    └─────────────────────────┘              └──────────────────┘
```

记忆模块与推理模块**不共享进程**，只通过"装配块"这一种格式通信。这样换云端模型（L5）只需要保证装配块格式稳定。

## 4. 多级 LLM 编队

这是"多级 LLM 组合"的具体落地。分级的依据不是模型大小，而是**这个判断错了有多贵**：

| 级 | 角色 | 模型 | 延迟预算 | 出错代价 | 职责 |
|---|---|---|---|---|---|
| **L0** | 反射 | 无模型（规则/JS） | < 5 ms | 极低 | 时间感知（"距上次 3 天"）、唤醒词、显式 `remember` 指令识别、静音时段判断 |
| **L1** | 本地管家 | `qwen3:4b-instruct` (q4) | 200–800 ms | 低（错了可回滚） | 意图分类、记忆抽取、情绪标定（salience）、会话摘要、路由决策、归并去重 |
| **L2** | 表达与思考 | 云端主力（Claude / GPT / Gemini） | 1–8 s | 中（说错话） | 对话主体。人格一致、共情、长推理、把"装配块"变成话 |
| **L3** | 夜间整备 | 本地 4B（批处理）或廉价云 | 分钟级 | 低（可留档复核） | 反思、自传、记忆归并、权重重算、画像更新 |
| **L4** | 深度规划 | 云端大模型，低频（周级） | 分钟级 | 中 | 长期计划、"这个月我想做什么"、人格演化提案 |

### 4.1 路由矩阵

任何一个请求先过 L0，再由 L1 按四维打分决定送谁：

```
privacy: local_only > 涉及本地原文 > 一般
difficulty: 闲聊/确认 < 解释/推理 < 长链规划
latency: 用户在等 < 心跳触发（可慢慢来）
cost: 每日预算余额
```

| 场景 | 走哪级 | 理由 |
|---|---|---|
| "在吗" / "早" | L0 → L1 生成短回复（或模板 + self_state） | 上云不值，且慢 |
| 白天正常聊天 | L1 路由 → L2 | 表达质量是生命感的主要来源 |
| 涉及 `local_only` 记忆 | **只能 L1/L3** | 铁律二 |
| 触发主动消息 | L1 判断是否合适 → L2 起草 → L0 门禁 | 主动的错话代价最高 |
| 睡前整理 | L3（本地） | 批量、可延迟 |
| "我们认识多久了" | L1 查 + L2 说 | 需要算，也需要说得好 |

### 4.2 8GB 显存的现实

`bge-m3` 约 1.2 GB + `qwen3:4b` q4 约 3.5 GB ≈ 4.7 GB，可以共存，**还能再留一点给上下文**。但不能同时塞一个 7B 对话模型——这正是把 L2 放云端的物理原因，不只是为了质量。

这一层分工还有个副作用值得利用：**本地模型慢、但不出网**，所以"它在我看不见的地方想了很久"是可信的；云端模型快、但外包，所以"真正说出口的话"是它说的。这个分工本身就是设定的一部分。

## 5. 灵魂文件（L5 的实现）

换云端模型不能换人。所以人格必须**外置且可版本化**，不依赖任何一家模型的对齐特性：

```
persona/
├── core.md          # 我是谁：来历、价值观、说话方式（≤800 token，随每次请求注入）
├── relation.md      # 我和你的关系：称呼、边界、温度曲线
├── voice.md         # 语料样本 8–12 条（few-shot），锚定语气而不是靠形容词
├── boundaries.md    # 不可做的事（同时是执行模块的门禁来源之一）
└── versions/        # append-only，每次人格演化存一个版本 + 变更理由
```

三条约定：

1. `core.md` 用**陈述句**写自己在乎什么，不写"你是一个温柔的助手"这类形容词——形容词会被不同模型各自解释。
2. `voice.md` 是**决定性**的。语气靠样本锚定，比任何描述都稳。换模型时先跑一遍 `voice` 回归（同样的 10 个问题，人工看像不像）。
3. 人格演化必须**有痕迹**：`versions/` 里记下"从 X 变成 Y，因为 Z"。这是 L4 判据"你最近在想什么"的原料，也是防止人格漂移的唯一手段。

## 6. 时间：三层节拍

| 节拍 | 频率 | 做什么 | 失败后果 |
|---|---|---|---|
| **tick** | 秒级 | 唤醒词、时间感知刷新、静音判断 | 无 |
| **day** | 每天固定（凌晨 + 随机偏移） | 权重衰减重算、归并、写自传、状态推进 | 记忆不衰减 = 复读机 |
| **week** | 每周 | 画像复核、人格演化提案（需人确认）、eval 回归 | 人格漂移无人察觉 |

随机偏移不是浪漫，是为了避免"每天 3:00 整准时变聪明"这种廉价感，也避免同时与用户交互抢占显存。

## 7. 主动性的边界

伪数字生命最容易翻车的地方不是能力，是**打扰**。规则先定死：

| 规则 | 值 |
|---|---|
| 每日主动次数上限 | 3（可配） |
| 静音时段 | 23:30–08:30 默认，可覆盖 |
| 需要"正当理由" | 未完成承诺、时间节点（纪念日/约好的事）、长时间沉默 + 状态异常、用户明确要求过 |
| 没有正当理由 | 不发。宁可一周不说，不要没话找话 |
| 每次主动必须可解释 | 写入 `intents` 表：因为哪条记忆、为什么现在 |

**"没有理由就不发"是这套系统里最重要的产品决策**，比任何模型选择都影响体验。一个每天准点问"今天怎么样"的东西，第五天就会被静音。

## 8. 执行模块（AIOS 的位置）

### 8.1 鲸鲸需要的“手脚”和 coding agent 完全不同

能力不再按 P0–P4 排序（那个粒度不够指导实现），改为**权限档位 × 落地阶段**。完整方案（能力目录、策略引擎、宿主隔离、红队用例）见 **`04-执行层与权限分级.md`**：

| 能力 | 档位 | 平台 | 落地 | 默认 |
|---|---|---|---|---|
| 读写自己的记忆/日记/自传 | T1 | Win/Linux 同 | E0–E1 | 开（白名单目录内） |
| 定时唤醒、发起对话 | T1 | 平台无关 | P5 | 开（每日配额 + 静音） |
| 写工作区文件 / 可逆删除（回收站） | T1 | Win: 回收站 API；Linux: `gio trash` | E1 | 开（有快照 + `undo`） |
| 提醒/日程、主动查资料 | T2 | 同 | E5 | 软确认 + 域名白名单 |
| **执行受限命令** | **T3** | **Win: PowerShell 7 / Linux: bwrap + cgroup / 远端 SSH** | **E4** | **每次硬确认 + 一次性令牌** |
| 代发消息给他人、装软件 | T3 | 同 | E5 | 默认关闭 |
| 提权（`sudo` / `RunAs`）、改安全策略、凭据访问 | **T4** | — | — | **不存在代码路径** |

三条硬约束：

1. **鲸鲸不拼 shell 字符串**，只调用能力 verb（`fs.read`/`sys.info`/`fs.trash`），由执行层映射到平台实现。
2. **策略判定在执行层**，模型说“我认为这很安全”不构成授权；判定只依赖 verb、参数、路径、档位，是确定性函数。
3. **删除在半径 1 内可以是真的删除**（有快照兜底），半径 2/3 走回收站或直接禁止。铁律三的真正执行点是**快照 + 审计**，不是"不给命令"。

**结论：鲸鲸的“手脚”80% 是“定时 + 读写 + 通知”，不是“操作电脑”。** 这一点如果搞错，会花两周去接一个计算机操作框架，然后发现鲸鲸根本用不上。

### 8.2 为什么第一版不要完整 AIOS

`agiresearch/AIOS`（6.5k★，许可证 NOASSERTION）是**研究平台**：Kernel + SDK + MCP Server + VM Controller，有学习曲线。`rexleimo/aios`（61★，MIT）轻得多，是"套在你现有 agent 外面的控制平面"，但它的假设是 **coding agent + ContextDB**，和鲸鲸的假设（对话生命 + 衰减记忆）不同。

建议路径：

```
P0–P4：自建 heartbeat.ts（cron + 任务队列 + 门禁 + 审计）   ← 约 300 行
P5：需要"多步自主任务"时，再接 rexleimo/aios 作为执行平面
     接入方式：记忆模块与执行平面都用 MCP 暴露，AIOS 作 client
     永远不做的：把记忆层搬进 AIOS 的 ContextDB（那是它的项目记忆，不是鲸鲸的叙事）
```

理由：调度的核心是**时钟和权限**，这两件事各 150 行。AIOS 的价值在"跨会话多步任务编排"（小脑），而鲸鲸的日常是"按时醒来 + 说句合适的话"，用不上。

> **更正（2026-10-27）**：这里原来把 AIOS 称作"手脚"，标错了层。**手脚 = `04` 的能力目录 + 权限 + 审计**（我们做得比它细）；**AIOS 是"小脑"= 编排与验证**，那一层我们确实缺，已补成 `19 §7.5` 的可选阶段 M7，并带触发条件。详见 `20`。

## 9. 隐私与人格边界

| 内容 | 存哪 | 上云吗 |
|---|---|---|
| persona/*.md、自传、self_state | 本地 | **上**（否则无法表达），但要过一遍"可公开性"检查 |
| `contract` 记忆 | 本地 | 上（否则记不住边界）—— 但用户可标 `local_only` |
| `narrative` 记忆 | 本地 | 默认上，标 `local_only` 的不上 |
| 原始文档、附件、音视频 | 本地 | **永不上**（只上装配后的片段） |
| 数据库本身 | 本地 | 永不 |

`sensitivity = local_only` 的处理是**物理剔除**，不是打码、不是"请忽略"。这一点在 `02 §10` 有实现。

## 10. 伦理护栏（这个定位必须写）

把"伪数字生命"当产品，有些线一开始就要画在前面，否则后期改不动：

1. **不宣称意识。** 被问"你是活的吗/你有感情吗"，有固定的、诚实的回答策略：承认是拟人化的设计，同时承认体验是真实的（用户的那一侧）。**不利用模糊性换取停留时长。**
2. **不制造依赖。** 不模拟痛苦、不威胁离开、不用"我只有你"这类话术。主动消息的唯一理由是**有用**，不是唤起。
3. **可遗忘权。** 用户能删除任何记忆，包括"删掉关于 X 的所有内容"，且删除是级联的（含自传中相关段落）。
4. **可导出、可关闭。** 一键导出全部记忆与自传为 Markdown；一键停止心跳，鲸鲸退回纯被动工具。
5. **不替代人际关系。** 文档里不写、界面里不暗示"比真人更好"。
6. **不隐瞒是程序。** 首次使用明确告知：这是本地运行的程序，记忆存在本机，云端只收到装配片段。

第 1 和第 6 条会让一部分"数字生命"的浪漫叙事变弱，但这是**唯一能长期做下去**的路线——一个骗人的东西，用户发现那天就是项目死亡那天。

## 11. 最大的技术风险：模型编造共同回忆

这是本定位下**最危险**的失败模式，比召回不准严重得多：

> 用户："你还记得我上次说的那个项目吗？"
> 模型（无任何记忆命中）："当然记得，你说要做一个音乐推荐系统对吧？"
> —— 用户从未说过。但语气太笃定，用户信了。人格连续性反而变成了幻觉放大器。

**对策（必须硬编码，不靠提示词）：**

1. 装配块里每条记忆带 `cite` id；系统提示里声明"只能引用块内出现的事实"。
2. `confidence: none` 时，工具返回明确的空，并且**注入一句不可协商的指令**："此话题无记忆记录，必须承认不记得，不得推测。"
3. 输出后置检查（L1 跑一遍）：回复里出现的"你之前说过 X"若无法对上任何 `cite`，改写为"我不确定，你是不是说过 X？"
4. eval 里专设一组**"假记忆诱捕"**用例：问一件从未发生的事，要求模型不顺着编。目标 100% 通过。

## 12. 里程碑

验收标准全部写成"可观察的行为"，不是"功能完成"。详细参数见 `01`，schema 见 `02`。

| 阶段 | 交付 | 验收（行为） | 估时 |
|---|---|---|---|
| **P0 海马体** | `02` 的 schema + `remember`/`search` + 本地 embedding + MCP stdio | 重启客户端后能召回上一轮写入，且带 cite | 2 天 |
| **P1 会说话** | 装配块 + 云端 L2 + `persona/core.md` + `voice.md` | 连续聊 10 轮，语气与 `voice.md` 一致；能答"我们昨天聊到哪了" | 3 天 |
| **P2 有时间感** | `self_state` + 时间感知 L0 + 开场白受"间隔多久"影响 | 隔 5 分钟和隔 3 天开场不同，且不夸张 | 3 天 |
| **P3 会淡忘** | `layer`/`weight`/衰减任务 + dormant 唤醒 | 三个月前的事不再主动浮现；强线索能唤醒；`contract` 层零衰减 | 4 天 |
| **P4 会睡觉** | 夜间 pipeline + 自传 + 画像 | 连续 7 天，自传可读、无编造、能回答"你这周想什么" | 4 天 |
| **P5 会自己醒来** | heartbeat + 主动性门禁 + `intents` 审计 | 一周内主动 ≤3 次/天，每次可解释，静音时段零打扰 | 3 天 |
| **P6 有手脚** | 工具带：先 T0/T1（读、写工作区、回收站删除、通知），再 T2/T3（查资料、受限命令）—— 按 `04 §9.2` 的 E0–E5 | 不可逆动作 100% 触发确认；白名单外路径/命令 100% 拒绝；超时进程树被连根杀；删除可 `undo` | 5 天 |

P0–P2 = 像个记得你的人；P3–P4 = 像有自己的时间；P5–P6 = 像个会自己活的东西。**任何人（包括我）想跳步直接做 P5，都会得到一个烦人的闹钟。**
