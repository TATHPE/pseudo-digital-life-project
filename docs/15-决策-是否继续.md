### 1.1 折算成我们自己的分级

> **OpenClaw ≈ L2（有时感的伴侣），不是 L3（有自我叙事的个体）。**

L3 的判据是 `0 §4` 那两条"半年测试"：
1. 能否提起**一件你已经忘了的事** —— 它大概能（memory_search + 触发器）。
2. 能否**改变一个从前的看法，并说清为什么** —— **它没有这个载体**：没有 agent 侧的"我的看法"被持久化，也没有自评驱动的变更记录。

**结论：定义里四条，它做到两条半。差的那半条（N2）恰好是定义里最难、也最关键的一条。**

## 2. 但这不该是决定依据

**"它差半条"不足以支撑一个项目。** 真正要问的是：**你要哪一个？**

| | 目标 A | 目标 B |
|---|---|---|
| 你想要 | 一个记得我、能主动找我、在我手机上说话的助手 | 一个会自己变、有立场、会淡忘、有自我叙事的东西 |
| OpenClaw | **已经超配** | 给了 80% 地基 + 一个 slot，但不给那 20% |
| 该做的事 | **停止自研，直接装** | **不写第二套记忆系统，写一个 memory runtime + 两个钩子** |
| 工作量 | 一天 | 1–2 千行 |
| 风险 | 无 | 可能发现"那 20% 也没那么重要" |

**如果目标是 A，我建议现在就停。** 不是因为它更先进，是因为 A 的工程量（20+ 渠道、五平台应用、5000+ 技能、权限体系、备份）比那 20% 的差异大两个数量级，而 A 是 90% 的场景。

**如果目标是 B，继续——但继续的方式要变**：不再从零造，只造那三件事（`14 §12`）。

### 2.1 决策更新（2026-10-27 晚）

用户判断：**OpenClaw 再完善也只是"老板的数字员工"，一切设计为效率服务；我们要的是有伪记忆、有个性、有空间的私人数字生命。**

这条判断在技术上成立，理由是**目标函数会渗透进每一个参数**——不是功能有没有，而是默认值偏向哪边：

| 参数 | OpenClaw 的默认 | 效率目标下必然如此 | 生命目标下应当 |
|---|---|---|---|
| 会话 | `session:auto-reset`（daily/idle） | 空闲就重置，省上下文 | **永不重置**，只有衰减 |
| 长历史 | `session:compact` 摘要替换旧消息 | 压到预算内 | **旧事变淡而不是被压缩** |
| 记忆排序 | `relevance × recency(30d) × importance` | 为"答对"服务 | 还要为"该不该现在想起来"服务 |
| 夜间整备 | `dreaming` 阈值 `minScore 0.75` | 只升够格的，控制噪声 | **允许低分的也留下，只是淡** |
| 降级 | provider 不可用即降级/回退 | 不能停 | **不能因为慢就说错话** |

于是三条决定（取代原 D-HOST 与 OpenClaw 实验）：

| # | 决定 | 影响 |
|---|---|---|
| **D1** | **主线回到自建**：Pi 当 hub，`jingjing` 自己实现 core（`14 §12` 的"钩子优先"作废，因为它依赖 OpenClaw） | 工作量回到 2000+ 行；但换回目标函数的控制权 |
| **D2** | **OpenClaw 降级为可选前端**：将来它可以作为 spoke / 一个客户端连我们的 MCP，而不是我们的宿主 | 保留 `11 §1` 方向 A；不再需要 D2/D3 嵌入深度 |
| **D3** | **不再装 OpenClaw 做三十天实验**；但 E2/E3 两个计数器**保留，转成我们自己的 eval 指标** | 省两周；`01 §13` 增加"遗忘合理性"与"分歧率"为常规项 |

## 3. 三十天实验（唯一的判据）

**不要靠讨论决定，靠用。**

装 OpenClaw，正常用两周，只记录三个数：

| # | 记录什么 | 计数方式 |
|---|---|---|
| **E1 惊喜** | 它因为"记得"而让你意外/省事的次数 | 正字计数 |
| **E2 烦躁** | 它"什么都记得一样重"而让你烦的次数（旧事翻出来、该淡的没淡） | 正字计数 |
| **E3 失望** | 它"没有立场/没有脾气/说了句正确的废话"而让你失望的次数 | 正字计数 |
| **E4 迁移** | 把 `data/` 从一台机器搬到另一台，能否无缝继续（`16 §2.1`） | 成功/失败 |

判据：

- **E3 = 0 且 E2 = 0** → 那 20% 对你不重要 → **停**。文档归档，项目结束，干净。
- **E2 ≥ 3** → 衰减形状是真需求 → 写 memory runtime（`14 §12` 第 1 件）。
- **E3 ≥ 3** → 人格与防编造是真需求 → 写两个钩子（第 2、3 件），且 `07` 那套要落地。
- **E1 一直为 0** → 连"记得"都不重要 → 停，且这个判断比任何架构讨论都值钱。

**这个实验的价值**：它用两周换掉两个月的可能白干。而且它不需要我们写任何代码。
